We are looking for a technical and detail-oriented Senior Automation Tester in JS to join our engineering team. In this role, you will move beyond manual verification and lead the charge in building, maintaining, and scaling our automated test suites. You will write code to test code, integrating automated checks directly into our delivery pipelines to ensure our software remains stable, reliable, and regression-free.

Responsibilities
  • Design, implement, and maintain robust automated testing frameworks for web applications, mobile apps, and backend APIs
  • Translate manual test cases and user stories into scalable, reliable, and maintainable automation scripts
  • Integrate automated test suites directly into CI/CD pipelines to enable continuous testing, automated regression runs, and rapid feedback loops for developers
  • Develop automated tests spanning multiple layers, including UI validation and API/microservices validation
  • Monitor automated test execution results, investigate and debug test failures, categorize flakiness, and maintain clear quality dashboards for the team
Requirements
  • 3+ years of proven experience as an Automation QA Engineer, Automated Testing Engineer, or SDET
  • Proficiency in JavaScript/TypeScript
  • Hands-on experience with modern automation frameworks and tools such as Playwright, Selenium, and Cypress
  • Familiarity with version control (Git) and CI/CD tools such as Jenkins, GitLab CI, and GitHub Actions
  • Understanding of software testing methodologies, test-driven development (TDD), and behavior-driven development (BDD)
  • English proficiency at B2 level or higher
