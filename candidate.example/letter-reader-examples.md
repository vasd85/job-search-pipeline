# Letter Reader Examples

## reread

**`reread`** — the sentence has to be assembled on a second pass.

- "At Tarnwick Studio the nightly run that the rebuild of the suite as layered code I led took from
  seventy minutes now ends in twenty-five." — *"I had to read it three times to find the verb."*

## unclear_reference

**`unclear_reference`** — a word points at something the letter has not put in front of the reader.

- "That is what I would like to bring to Perrinault." — *"Bring what? Nothing before it is named."*

## missing_link

**`missing_link`** — the conclusion is there, the step it stands on is not; or the colon promises an
explanation and delivers a different thought.

- "The nightly run went down to twenty-five minutes, so the team trusted the suite again." —
  *"Why would a faster run make anyone trust it?"*

## translated

**`translated`** — the words are the letter's own language, the sentence is not.

- "In the question of unstable tests I have a big experience." — the reader heard a word-for-word
  translation in it.
